| **γίνομαι**                    | становиться, происходить | pres. med.; aor. **ἐγενόμην**    |
| **πορεύομαι**                  | идти, отправляться       | med.; aor. **ἐπορεύθην**         |
| **ἀποκρίνομαι**                | отвечать                 | med.; aor. **ἀπεκρίθην**         |
| **δέχομαι**                    | принимать                | med.; aor. **ἐδεξάμην**          |
| **φοβέομαι**                   | бояться                  | med./pass.; aor. **ἐφοβήθην**    |
| **δύναμαι**                    | мочь, быть способным     | med.; aor. **ἠδυνήθην**          |
| **βούλομαι**                   | хотеть, желать           | med.; aor. **ἐβουλήθην**         |
| **ἡγέομαι**                    | считать; вести           | med.; aor. **ἡγησάμην**          |
| **λογίζομαι**                  | считать, полагать        | med.; aor. **ἐλογισάμην**        |

| **θεάομαι**                    | видеть, созерцать        | med.; aor. **ἐθεασάμην**         |
| **ἰάομαι**                     | исцелять                 | med.; aor. **ἰασάμην**           |
| **ἀρνέομαι**                   | отрицать, отрекаться     | med.; aor. **ἠρνησάμην**         |
